# The Vacuum's Alibi: One Line, 200 Characters

A make.fun entry: the funniest one-line excuse a robot vacuum can give for missing a spot, in 200 characters or fewer.

`main.py` (pure Python 3.13 stdlib) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line, in the vacuum's own deadpan voice:

> I left that corner alone because my bump sensor classified the dust bunny as load-bearing, and I don't demolish structures.
